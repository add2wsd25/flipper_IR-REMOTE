# 📺 Samsung TV IR Remote for Flipper Zero

This file contains infrared (IR) codes for older Samsung TVs, created for use with the Flipper Zero.

## ⚙️ Installation

1. Access your Flipper's SD card storage.  This can be done through various methods:
    * Using the [qflipper](https://github.com/flipperdevices/qFlipper) desktop application.
    * Using the [iOS](https://apps.apple.com/us/app/flipper-mobile-app/id1534655259) and [Android](https://play.google.com/store/apps/details?id=com.flipperdevices.app) Flipper mobile app.
    * Using the [Flipper web application](https://lab.flipper.net).
    * Directly reading the SD card with an SD card reader.

2. Navigate to the desired folder on your Flipper's SD card where you want to store the IR file (e.g., `/ir`).

3. Transfer the IR file to that folder.

4. Eject the SD card from your Flipper or disconnect it from your computer.
